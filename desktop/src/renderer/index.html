      Pasang SSL Nginx
      Let's Encrypt melalui Certbot, langsung pada VPS aktif.
      Domain harus sesuai dengan vhost Nginx di VPS ini dan challenge HTTP harus dapat dijangkau melalui port 80. Alur ini tidak mendukung wildcard.
      Pisahkan beberapa domain dengan koma atau spasi. Masukkan semua domain yang ingin dilindungi.
      
  
      Siapkan SSL untuk Nginx
      Instalasi Certbot untuk Ubuntu / Debian.
      1. Pastikan Nginx sudah melayani domain di VPS dan port 80 dapat dijangkau dari internet.
      2. Jalankan command berikut di terminal VPS untuk memasang Certbot dan plugin Nginx.
      sudo apt update &&
sudo apt install -y certbot python3-certbot-nginx
      Kembali ke SSL Manager, pilih Muat ulang, lalu Pasang SSL. Sertifikat dan private key tetap berada di VPS. LabServer tidak membuat scheduler renewal; periksa timer/cron Certbot pada server Anda.
      Versi pertama mengelola Certbot pada Nginx host. Import Cloudflare Origin, wildcard/DNS-01, dan Nginx dalam container belum didukung.
      Dokumentasi Certbot Nginx

      Siapkan Docker di VPS
      Gunakan Docker Engine sesuai distribusi Linux server.
      1. Buka panduan resmi Docker, lalu ikuti instalasi untuk OS VPS Anda.
      2. Pastikan Docker daemon berjalan dan akun SSH dapat mengaksesnya.
      3. Kembali ke Docker Manager dan pilih Muat ulang. Jika akses ditolak, pilih Gunakan sudo sesuai izin akun Anda.
      Versi ini memakai socket standar /var/run/docker.sock. Docker rootless dengan socket khusus dan daemon remote belum didukung. LabServer tidak mengubah izin socket atau grup akun secara otomatis.

      Tambah record DNS
      
    
      Gunakan @ untuk domain utama, atau nama seperti www dan api.
      Proxy tersedia untuk A, AAAA, dan CNAME. Record yang diproxy memakai TTL otomatis.
      
        
  
      Buat API Token Cloudflare
      Satu token dapat dibatasi ke domain yang ingin Anda kelola.
      1. Buka halaman API Tokens Cloudflare dan login ke akun Anda.
      2. Pilih Create Token, lalu template Edit zone DNS.
      3. Pastikan ada izin Zone / DNS / Edit dan tambahkan Zone / Zone / Read agar LabServer dapat menampilkan domain.
      4. Di Zone Resources, pilih domain yang ingin dikelola. Pilih Continue to summary → Create Token.
      5. Salin token yang ditampilkan, lalu masukkan ke LabServer bersama memo / label akun. Token hanya ditampilkan sekali oleh Cloudflare.
      Memo adalah nama pengenal di LabServer, bukan email Cloudflare. Gunakan API Token, bukan Global API Key. Token tersimpan terenkripsi dan ikut dalam backup .lsb; record DNS tetap berada di Cloudflare.
      Buka Cloudflare API Tokens
