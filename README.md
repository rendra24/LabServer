# LabServer

Aplikasi desktop (Electron, macOS/Windows) untuk mengelola Nginx dan server lewat SSH tanpa agent: editor vhost, `nginx -t`, reload aman, monitoring Prometheus, dan lainnya.

- Kode dan cara menjalankan: [`desktop/`](desktop/README.md)
- Rilis: [`desktop/RELEASING.md`](desktop/RELEASING.md)
- Dokumen produk: [`docs/desktop/`](docs/desktop/PRD.md), keputusan di [`docs/DECISIONS.md`](docs/DECISIONS.md)

Versi web lama (FastAPI + PostgreSQL) sudah dihapus dari tree; riwayatnya ada di git sampai commit `645f625`.
